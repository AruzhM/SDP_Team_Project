## Визуальная проверка

Проверены реальные снимки JavaFX-сцены 960 × 720: направленные волны и мишень у левой стены, активный диалог Хикари в коридоре. При дополнительной проверке обнаружено перекрытие новой панели длинным диалогом; исправлено временным скрытием панели и дублирующего сюжетного сообщения на время диалога. Итоговый полный прогон выполнен после исправления.

Снимки можно воспроизвести:

```bash
mvn -Pheadless-tests -Dsdp.screenshotDir=target/screenshots test
```

Проверка в headless JavaFX подтверждает работу сцены и обработчиков. Отдельный интерактивный прогон на Windows/macOS в этой среде не выполнялся.
